# Fitness Site

## What this is
A GitHub Pages site (MkDocs) with a workout routine and a nutrition plan derived from it.
All content lives as Markdown in docs/. No web app, no JS, no databases.

## Stack
- MkDocs with Material theme → deployed to GitHub Pages
- All content is plain Markdown tables and lists

## Key rules
- Never create .html, .jsx, or .js files
- Nutrition plan must always reference the current workout routine
- Keep docs/ files human-readable without rendering

## User profile
- Age: 34
- Weight: 85kg | Height: 183cm | BMI: ~25.4
- Goal: gradual muscle gain + weight control (recomposición corporal)
  - Small surplus on training days to build muscle
  - Maintenance/slight deficit on rest days to avoid fat gain
- Gym: 3–4 days/week, upper/lower split, abs + cardio every session
- Eating style: tends to eat slightly above maintenance — plan should work WITH
  this via high-satiety, high-volume foods rather than restriction
- Beer: 2–3 sessions/week (~2 beers each, ~300–400 kcal to budget per session)
- Nutrition market: Spain (Mercadona, Carrefour, Ahorramas, Alcampo, Lidl España)
- Content language: Spanish
